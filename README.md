#  Match Strike Portfolio

> 🔥 A modern, responsive developer portfolio showcasing projects, skills, and experience, built with React and styled using Tailwind CSS.

This repository hosts my personal portfolio website, designed to serve as a central hub for my work, technical abilities, and contact information. The design emphasizes a clean, responsive, and visually appealing user experience, featuring a dynamic experience timeline and skill badges.

## 🛠️ Tech Stack

This project is built using modern frontend technologies:

* **Framework:** [React](https://react.dev/) (Utilizing hooks like `useState`, `useEffect`, and `useRef` for component logic and animations)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first approach for responsive design and custom styling)
* **Language:** JavaScript (ES6+)
* **Build Tool:** Vite
* **Icons:** [React Icons](https://react-icons.github.io/react-icons/)

## 💻 Getting Started

### Prerequisites

You need **Node.js** (LTS recommended) and **npm** installed on your machine to run this project locally.

### Installation and Local Run

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/NikoLewis/match-strike-portfolio.git](https://github.com/NikoLewis/match-strike-portfolio.git)
    cd match-strike-portfolio
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run the development server:**
    ```bash
    npm run dev
    ```
    The application will typically be available at `http://localhost:5173/`.

## 📂 Key Features & Components

The portfolio is structured into clear, modular sections:

* **Contact Section:** Features a responsive layout using Flexbox, showcasing social links and contact information alongside a stylized image.
* **Experience Section:** Displays professional history in an interactive, alternating timeline format (`ExperienceItem` component).
    * Includes custom styling for skill badges and responsive card sizing.
    * Uses **Intersection Observer API** for scroll-triggered entry animations.
* **Styling Consistency:** Components feature a consistent dark theme, custom pink/cyan accent colors, and responsive padding (`p-6 sm:p-8`) for visual continuity.
